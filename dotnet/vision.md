Die Vision

Was soll das Tool am Ende machen?

Das Tool soll alte XMLs von Intelligen bekommen diese lesen und die entsprechenden Felder füllen.

Felder die es nicht füllt sollen mit entsprechenden Crawlern wie Xrel, IMDB und so weiter befüllt werden.

Die Felder der XML sollen dann in ein variables vom user definiertes Template geladen werden, der user soll hier auch eine Vorschau möglichkeiten haben.
Er soll auch neue Templates anlegen können und editieren können. Ein Template soll und kann bestimmten Kategorien wie Movie und so weiter zugeordnert werden können.

Wenn der User alles befüllt hat soll den Eintrag veröffentlichen können auf allen von ihm aktivierten Seiten und Boards.

Es soll dann so eine Art History oder Liste geben wo er alles was er veröffentlicht hat sieht und im Fehler falle dies an bestimmte Seiten nochmal senden kann.

Das Plugin System soll vorhanden bleiben da es ja verschiedene Crawler, Imagehoster für Cover und Publish Seiten gibt.

Das soll alles clean und intuitiv zu bedienen sein. Die UI soll modern, gut strukturiert und sauber aussehen.


Der neue Code soll natürlich im neuen /dotnet Ordner liegen.
